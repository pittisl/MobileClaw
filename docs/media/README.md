# MobiCom 2026 presentation media

- [Poster PDF](poster.pdf): 40 × 30 inch poster.
- [Poster preview](poster.png): PNG image of the poster.
- [Demo video](https://github.com/pittisl/MobileClaw/raw/refs/heads/main/docs/media/demo.mp4): MP4, 1920 × 1080, 2 min 59 sec, English narration and subtitles.
- [English subtitles](demo.en.srt): SRT transcript timed to the demo video.
- [Video cover](demo-preview.jpg): preview image for the demo video.

These materials accompany **Demo: MobileClaw: A Notification-Driven,
Human-Gated Mobile LLM Agent**, by Boyuan Yang, Alexander Du, Ozzie Hassel,
Jash Uganandan and Wei Gao, ACM MobiCom 2026.

- [Project repository](https://github.com/pittisl/MobileClaw)
- [Paper](https://doi.org/10.1145/3795866.3848463)
