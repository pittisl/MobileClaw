# MobiCom 2026 demo booth — checklist (Austin, Oct 26–30)

Setup time: 8:30 am on demo day, table 14 in the demo hall.

Bring:
- 3 Android phones with MobileClaw installed and the demo Google account signed in
- 3 laptops, one per phone, each running the trace window (`adb logcat -s MobileClaw-TRACE`)
- power strip (6 outlets), 3 USB-C cables, phone stands
- poster tube (poster is 36 × 48 in, portrait)
- printed one-page handout, 100 copies
- backup video clips on each laptop in case the Wi-Fi fails

Reset between visitors: clear notifications, long-press Clear chat, Memory → Forget everything.
